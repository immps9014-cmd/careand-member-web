## 0. 요약 (한 줄 결론)

**careand는 "매칭·가격 엔진"에서 케어네이션을 앞선다** (동적 적정간병비 견적 + 역경매 입찰 + AI 추천 + 공급자 pull 지원 — 케어네이션엔 없거나 미노출). **격차는 대부분 "신청 UX·전환 설계·컴플라이언스 고지" 영역**이다 — 멀티스텝 위저드, 캘린더/반복요일, 서비스 항목 멀티셀렉트, 부적격 스크리닝, 직거래/위약금 고지, 서비스 안내(제공/미제공) 화면.

→ 로드맵의 핵심은 **신규 엔진 개발이 아니라, 이미 강한 백엔드를 시니어 친화 UX로 포장**하는 것.

## 2. 갭 분류

**A. 전환율에 직접 타격 (신청 UX)** — #1,2,3,4,5
단일 폼이 길어 시니어 이탈 위험. 케어네이션의 3스텝 분해가 정석.

**B. 신뢰·분쟁 예방 (컴플라이언스/안내)** — #12,13,15,18,19
서비스 범위 미고지·부적격 미차단·직거래 미고지 → 운영 리스크. 저비용/고효과.

**C. 도메인 완결성** — #11,22
동행 도메인 경로설계 미구현, 실제 결제 UI 부재.

**D. 마감 디테일** — #14,20(일부 폼),24,25,26
가이드북, 일부 폼 Daum 미연동, 프로모 뱃지, 톤.

## 3. 우선순위 로드맵

우선순위 = (전환/신뢰 임팩트) ÷ (구현 비용). careand는 백엔드가 이미 있어 **프런트 UX 작업 위주**라 대부분 저비용.

### 🔴 P0 — 즉시 (1~2주, 고임팩트·저비용)

| 항목 | 작업 | 근거 갭 | 예상 규모 |
|---|---|---|---|
| **P0-1 신청폼 3스텝 위저드화** | `request/new` 단일폼 → (1)대상·서비스 (2)일정·상세 (3)확인 3스텝 + 공용 `<StepIndicator>` 컴포넌트 신설. 필드·API 그대로, 뷰만 분할 | #1,#2 | 중 (프런트만) |
| **P0-2 컴플라이언스 고지 삽입** | 각 스텝 하단 반복 고지: 직거래 금지·위약금·상태 고지 의무. 확인 스텝에 요약+필수 동의 체크 | #18,#19 | 소 (카피+체크박스) |
| **P0-3 서비스 안내 화면** | 신청 진입 전 도메인별 "제공/미제공 범위 + 이용불가 대상자" 안내 카드(케어네이션 패턴) | #12,#13 | 소~중 (정적+도메인 레지스트리 활용) |
| **P0-4 부적격 스크리닝 게이트** | 안내 화면에 이용불가 대상 체크리스트 → 해당 시 신청 차단/안내. 대상자 폼 최소 검증 강화 | #13 | 소 |

### 🟠 P1 — 다음 (2~4주, 전환·완결성)

| 항목 | 작업 | 근거 갭 | 예상 규모 |
|---|---|---|---|
| **P1-1 서비스 항목 멀티셀렉트** | 가사/생활지원 등 도메인에 서비스 항목 칩 다중선택(최소 N개 규칙) 도입, 매칭 정확도·견적 파라미터로 연결 | #3 | 중 (백엔드 파라미터 확인 필요) |
| **P1-2 커스텀 캘린더 + 반복요일** | `datetime-local` → 캘린더 다중선택 + 요일반복(recurrence_rule.days 활용, 요일 지정). 시작일+30/45일 제한 | #4 | 중 |
| **P1-3 종료시각 실시간 표시** | 시작+소요→"15시~18시" 요약 박스(총액 계산 로직에 붙임) | #5 | 소 |
| **P1-4 도메인 크로스셀** | 안내/결과 화면에 "○○ 필요 시 △△ 서비스" 유도(6도메인 레지스트리 기반) | #15 | 소 |
| **P1-5 나머지 폼 Daum 연동** | postpartum/children/mental 폼 자유텍스트 → Daum Postcode 통일 | #20 | 소 |

### 🟡 P2 — 이후 (한 달+, 도메인 확장·마감)

| 항목 | 작업 | 근거 갭 | 예상 규모 |
|---|---|---|---|
| **P2-1 결제(PG) 연동** | 선결제/정산 연결, 결제 UI. 백엔드 결제 도메인 설계 선행 | #11 | 대 |
| **P2-2 동행 도메인 경로설계** | 만남→방문→복귀+경유지, 이동수단 제약, 현장 본인확인. 동행 서비스 정식화 | #22 | 대 |
| **P2-3 수요자 가이드북/온보딩** | 첫 이용자 가이드 배너·튜토리얼 | #14 | 소~중 |
| **P2-4 프로모 뱃지·홈 허브 정비** | Badge에 NEW/HOT/BETA variant, 홈 도메인 타일 정비 | #24 | 소 |
| **P2-5 시니어 친화 톤 검토** | 폰트 크기·대비·톤 A/B (디자인 결정 필요) | #26 | 중 (디자인) |

## 4. 의도적 비채택 (하지 말 것)

- **광고 배너 과삽입**(메리츠화재 등): 케어네이션은 수익화하나 careand 신뢰도엔 역효과 — 채택 보류.
- **역경매/AI추천 축소**: careand 우위 자산 — 케어네이션에 맞춰 단순화 금지.

## 5. 다음 액션 제안
