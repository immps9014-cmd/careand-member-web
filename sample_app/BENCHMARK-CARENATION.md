## 1. 산후돌봄 (세트 A)

- **태그라인**: "산모와 아이의 일상을 함께하는 맞춤형 돌봄 서비스"
- **흐름**: 홈 → 신청 전 안내 → **STEP1 일정** → **STEP2 대상** → **STEP3 희망서비스** → 상세 검토 → 동의·등록

### 주요 화면
- 홈: 산후돌봄/아이돌봄 카드, 진행·완료 내역(0건), 가이드북 배너
- 안내: 신청 불가 대상자(산모 의사소통 불가/정신질환 치료중 등), 의료서비스 미제공 고지
- STEP1 일정: **출퇴근/입주** 유형 분기, "산후조리원 이용?" → 조리원명·퇴소일 연동, 캘린더 다중선택(**최대 45일**), 시작시간+신청시간→종료시각·총횟수 자동 산출("15시~19시, 총 8회")
- STEP2 대상: 산모/아기/둘 다 선택, 산모 정보(이름·나이), 아기 정보(이름·성별·만나이+개월·몸무게, **최대 2명 추가**)
- STEP3 희망서비스: 산모(수유보조·좌욕기·낮잠보장 등)/아기(목욕·배꼽소독·트림·병원동행 등)/가사(유축기관리·이유식·설거지·세탁 등) **대분류 × 다중선택 칩** + 자유서술(**750자 카운터**)
- 근무조건: 방개수·동거인·반려동물·식사제공·선호성별·**희망시급 직접입력(하한 16,000원)**
- 최종: 민감정보·제3자 제공 동의(필수), 직거래 금지 경고, 등록하기

### 가격/결제
- **희망시급 사용자 입력형(역경매성)** — 하한 16,000원, "낮으면 매칭 어려움" 경고
- 금액 = 플랫폼 수수료 + 부가세 포함, **선결제 후 케어메이트 선택**으로 최종 매칭
- 예시(세트 내 유일한 금액 노출): 가사돌봄 공고 **총 결제 108,672원**
- 결제 후 일정변경 불가, 개인 간 직거래 금지(위반 시 영구 탈퇴)

## 2. 가사돌봄 (세트 B)

- **태그라인**: "청소부터 식사 준비까지, 가사돌봄이 필요하시다면 이용해 보세요."
- **흐름**: 홈 → 서비스 안내(제공/미제공/불가 대상자) → **공고 등록 3스텝(장소 → 상세·일정 → 확인)** → 공고 상세

### 주요 화면
- 홈: 신청 현황(0건), 가이드북, 메리츠화재 보장분석 광고 배너
- 안내: 제공 항목(바닥청소·설거지·빨래·쓰레기배출·식사준비 등), **미제공**(전문청소·손걸레질·베란다·손빨래·냉장고정리·장보기·아이돌봄 등), 불가 대상자 → 간병 필요 시 "케어네이션 간병 서비스" **크로스셀**
- STEP1 장소: **카카오맵** 주소검색·지도핀·상세주소(동/호), 빈 상태 일러스트
- STEP1 상세: 평수(18평 미만~40평+)·방개수·동거인·반려동물(예→종류/유의사항 **조건부 필수**)·건조기 유무·추가 전달사항 → "정보에 따라 요금 상이" 고지
- 서비스 선택: 항목 **최소 4개 이상** 다중선택
- STEP2 시간/일정: 시작시간+이용시간(시간 단위) 드롭다운(08~23시), 요일 반복(고정 돌봄일), 캘린더(**시작일+30일 제한**)
- 대상자 정보: 몸무게·진단명(+없음 체크)·장기요양 수급자 여부, 상태 고지 의무
- 공고 상세: "시간제 가사돌봄", 개인정보 **마스킹**(강\*규), 섹션별 "수정하기"

### 가격/결제
- **동적 견적**: 평수·방·동거인·건조기·서비스 항목 수 → 이용금액 차등, 시간제 과금
- 서비스 범위 변경 = 금액 영향, 매칭 후 일정변경 불가 시 위약금

## 3. 동행 / 병원 이동보조 (세트 C + 세트 B 후반부)

- **태그라인**: "케어메이트가 환자의 이동을 보조해드립니다 — 집에서 원하는 목적지까지!"
- **흐름**: 홈 → 동행 메인(진행/완료 내역) → 준비물 안내 → 대상자 선택 → 환자정보 → **일정·경로·이동수단**(3스텝) → 현장 본인확인 질문

### 주요 화면
- 준비물 안내: **현장 실비(교통비) 결제 카드 + 휴대전화 환자 지참** 방식
- 대상자: 본인/가족·지인, **이용 불가 대상자 상세 고지**(만19세 미만·응급/중증·의사소통 불가·인지장애(치매/섬망)·정신질환·와상/휠체어 전용)
- 환자정보: 이름·성별·나이·키·몸무게·진단명(+없음 체크)·보행상태(스스로/부축/기타)·장기요양 여부, 보호자 상태 고지 의무
- 일정: 시작 05~20시/종료 23시 안내, date picker, 시작시간+소요시간 → 종료시각 자동 계산
- **경로 설계(세트 B)**: 만남 장소 → 방문 장소 → 복귀 장소 + 경유지 추가, "복귀=만남 동일" 토글, 이동수단 **택시·대중교통만(자가용 불가)**, 교통비 보호자 결제
- 현장 본인확인: 환자 이름·생년월일 등 안전 확인 질문

### 가격/결제
- 앱 내 명시 요금 미노출 — **교통비 등 부대비용은 현장 실비 직접 결제**
- 수익화: 제휴 의료광고(성남 성모윌병원), 메리츠화재 보장분석 배너, 어르신세상 센터장 모집

## 4. 공통 UI/UX 패턴 (3개 서비스 공유)

- **내비게이션**: 상단 뒤로가기+타이틀, 하단 5탭(홈/커뮤니티/중앙CTA/일정관리/마이페이지), 다단계 폼은 우상단 **①②③ 원형 스텝 인디케이터** + 하단 고정 "이전/다음"(다음=갈색 primary).
- **컬러/브랜딩**: 브라운·베이지 톤 + 선택 시 연핑크 하이라이트, 시니어 친화 고대비·큰 폰트, 물결(∽) 심볼.
- **카드/리스트**: 라운드 카드, 항목별 라인 아이콘/일러스트, 내역은 카운트("0건 >")형, 정보그룹마다 "수정하기" 인라인 버튼.
- **폼**: 라디오 카드(단일)·다중선택 칩("중복 선택 가능" 강조), 조건부 필드(반려동물 예→상세, 조리원 네→퇴실정보), 단위 접미사(세/cm/kg), placeholder 예시, 글자수 카운터, 빈 상태 일러스트.
- **주목 인터랙션**: **입력값 기반 실시간 계산**(시작+소요→종료시각 자동), 캘린더 원형 셀렉트+초기화, 툴팁("설명이 필요하다면 눌러주세요"), 요약 박스, 상시 챗봇/전화 상담 FAB.
- **컴플라이언스 UX**: 매 스텝 하단에 위약금·일정변경 규정·불가 대상자·직거래 금지 **반복 고지**, 개인정보 마스킹, 필수 약관 동의.

## 5. member-web 벤치마킹 시사점 (우선순위)

1. **다단계 신청 위저드 + 스텝 인디케이터 + 실시간 계산**
   상단 ①②③ + 하단 고정 이전/다음, "시작 15시 + 3시간 → 15~18시" 자동 안내. 시니어 이탈 감소 정석 패턴 → careand 예약/매칭 플로우에 이식.

2. **대상자 프로파일링 → 동적 견적 / 희망시급 직접입력**
   평수·방·동거인·반려동물·건조기 등 구조화 질문을 그대로 **가격 파라미터로 매핑**. 희망시급 하한·"낮으면 매칭 저하" 마이크로카피는 careand **적정간병비 산출·역경매 입찰 레이어**와 정확히 맞닿음.

3. **다중선택 칩(대분류×중복) + 자유서술(카운터) + 조건부 필드**
   희망 서비스 상세를 매칭 정확도 향상용으로 수집. 조건부 필수 필드/빈 상태 일러스트 채용.

4. **제공/미제공/불가 대상자 명시 + 크로스셀 + 컴플라이언스 고지**
   기대치 관리·분쟁 예방. "간병 필요 시 간병 서비스로" 식 도메인 간 유도는 **careand 6도메인 멀티도메인** 전환율에 활용. 단, 광고 배너 과삽입은 신뢰도 측면에서 절제.

5. **시니어 친화 비주얼 규범**
   큰 폰트·고대비·따뜻한 브라운 톤·항목별 일러스트·상시 상담 FAB·단계별 규정 반복 고지.
